# Power BI Business Intelligence Project

## Project Title
Sales Performance, Profitability & Business Intelligence Dashboard

## Project Overview
This project is developed using Power BI to analyze sales performance, profitability, customers, products, salespeople, geographic performance, and budget versus actual sales.

The dashboard provides interactive insights to help understand business performance and identify important trends.

## Objectives
- Analyze overall sales and profit performance
- Analyze yearly, quarterly, and monthly sales trends
- Identify top-performing products and customers
- Analyze salesperson performance
- Analyze geographic sales performance
- Compare actual sales with budget
- Provide interactive business insights using Power BI

## Dashboard Pages
1. Executive Overview
2. Sales Trend Analysis
3. Product Performance
4. Customer Analysis
5. Salesperson Performance
6. Geographic Analysis
7. Budget vs Actual
